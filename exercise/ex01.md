### Part 1

You will need a CS undergraduate linux account for this class. Here are options for obtaining an account. We will be using them in class starting this Friday!

* If you have one already, then use that.
* If you are a declared CS major/minor, get a “permanent account” from the <a href=
"https://support.cs.jhu.edu/wiki/Obtaining_CS_Computer_
Accounts" target="_blank">CS IT website</a> according to the instructions posted there (download form, fill in your info, email to support@cs.jhu.edu). You will then need to meet with an IT staff member to "pick up" your account information. 
* Otherwise, send “all instructors” a private post on Piazza with
subject “Request for a temp cs account”. Include your name, JHED ID, and course section number in the request post. We will get back to you with the user name and password for a temporary account to use this semester once your course registration is verified.

Next, **everyone** should log into Canvas, go to this course, then click through to Piazza in the left menu.  Carefully read through the account and lab usage policies posted in Piazza @6 and the course posting policies in Piazza @9. 


### Part 2

Create a Github account and provide us with the user name:

1. Create a free account at <a href="https://github.com/join">Github</a>, if you do not have one already.

2. Once created, fill in this <a href="https://forms.gle/vgLtpskFiwFQusYh9" target="_blank">Getting Started Form</a> **as soon as possible**.

3. Look out for an invitation email from Github in the mailbox of the email address you used to sign up for Github. Accept the invitation to join the course Github organization.
